Hosted Endpoint

Your MCP server will be live at:

https://fastapi.genalpha.dev/mcp

# Add to Claude Desktop config:
{
  "mcpServers": {
    "fastapi": {
      "url": "https://fastapi.genalpha.dev/mcp"
    }
  }
}

Install & Run

Your stdio MCP server via pip:

pip install fastapi-genalpha-mcp

# Add to Claude Desktop config:
{
  "mcpServers": {
    "fastapi": {
      "command": "fastapi-genalpha-mcp",
      "args": ["--base-url", "https://api.example.com"]
    }
  }
}

# Or run directly:
fastapi-genalpha-mcp serve
