How it works

Three steps. Zero config.

From GitHub URL to installable tools. No configuration files, no manual mapping, no boilerplate.

01

Parse

Paste a GitHub repo URL. We clone it, detect the framework, and extract every API route via OpenAPI specs + Python AST analysis.

→
02

Visualize

See your API as an interactive mindmap. Routes grouped by resource, color-coded by HTTP method. Review before generating.

→
03

Generate

Download a pip-installable CLI tool or a FastMCP server. Auto-registered with Claude Desktop. Ready to use.

Features

Built for developers who ship

⚡

Two-Layer Parsing

OpenAPI spec detection + Python AST extraction. Cross-file router prefix resolution. DI param filtering. Full Pydantic model schemas.

⚙

CLI Generator

Typer CLI with positional path params, body flags, --pretty output, --body JSON override. pip-installable from the zip.

◆

MCP Server

FastMCP with @mcp.tool() per route. Async httpx client. Auto-registers with Claude Desktop. stdio transport.

🔒

Private Repos

Connect GitHub via OAuth. Tokens encrypted with Fernet. Auto-refresh. Parse private repos securely through our TPS service.

★

API Mindmap

React Flow visualization with dagre layout. Routes grouped by path prefix. Click any node to see params, types, and response format.

⚡

Temporal Workflows

Durable parse + generate pipelines. Per-step progress. Auto-retry on failure. Live status updates in the browser.

Frameworks

Parse any Python API

We support major Python frameworks with more coming. Java and Go support planned via tree-sitter.
