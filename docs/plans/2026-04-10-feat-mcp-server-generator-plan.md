# feat: MCP Server Generator

## Overview

Add MCP server generation to `genalphacli build`. Given a command graph JSON, generate an installable MCP server where every API route becomes an MCP tool that AI agents (Claude Desktop, Cursor) can call directly.

## Problem Statement

We can generate CLI tools from graph.json, but AI agents can't use them. MCP servers bridge this gap — any parsed API becomes accessible to Claude, Cursor, and other MCP clients through natural language.

## Proposed Solution

Jinja2 template-based MCP server generator using `fastmcp` standalone SDK + `httpx` async HTTP client. Same proven pattern as CLI generator. The `build` command gets multi-select checkboxes so users can generate CLI, MCP server, or both from one graph.json.

## Technical Stack

| Component | Library | Notes |
|---|---|---|
| MCP SDK | `fastmcp>=3.0` | Standalone, `@mcp.tool()` decorators |
| HTTP client | `httpx>=0.27` | Async, connection-pooled via lifespan pattern |
| Templates | Jinja2 `SandboxedEnvironment` | Reuse existing generator infra |
| Transport | stdio | Claude Desktop spawns process. Streamable HTTP later. |

### Generated server.py (target output)

```python
"""MCP server for myapi. Auto-generated by genalphacli."""

import json
import os

from fastmcp import FastMCP, Context
from fastmcp.exceptions import ToolError
from myapi_mcp.client import api_call, init_client, close_client

mcp = FastMCP(
    name="myapi",
    instructions="API bridge for myapi. Tools map to REST endpoints.",
)

@mcp.tool()
async def list_users(limit: int = 10, offset: int = 0) -> str:
    """List all users. GET /api/v1/users"""
    try:
        result = await api_call("GET", "/api/v1/users", params={"limit": limit, "offset": offset})
        return json.dumps(result, indent=2)
    except Exception as e:
        raise ToolError(str(e)) from e

@mcp.tool()
async def get_user(user_id: str) -> str:
    """Get a user by ID. GET /api/v1/users/{user_id}"""
    try:
        result = await api_call("GET", f"/api/v1/users/{user_id}")
        return json.dumps(result, indent=2)
    except Exception as e:
        raise ToolError(str(e)) from e

@mcp.tool()
async def create_user(name: str, email: str) -> str:
    """Create a new user. POST /api/v1/users"""
    try:
        result = await api_call("POST", "/api/v1/users", json_data={"name": name, "email": email})
        return json.dumps(result, indent=2)
    except Exception as e:
        raise ToolError(str(e)) from e

def main():
    mcp.run(transport="stdio")

if __name__ == "__main__":
    main()
```

### Generated client.py (async httpx)

```python
"""Async HTTP client for myapi MCP server."""

import json
import os
import sys
from typing import Any

import httpx

BASE_URL = os.environ.get("MYAPI_BASE_URL", "https://api.example.com")
AUTH_TYPE = "bearer"
AUTH_ENV_VAR = "MYAPI_TOKEN"
TIMEOUT = 30
MAX_RESPONSE_SIZE = 50000  # 50KB truncation limit

_client: httpx.AsyncClient | None = None

async def get_client() -> httpx.AsyncClient:
    """Get or create the shared async HTTP client."""
    global _client
    if _client is None:
        _client = httpx.AsyncClient(
            base_url=BASE_URL,
            timeout=TIMEOUT,
            limits=httpx.Limits(max_connections=20, max_keepalive_connections=10),
        )
    return _client

async def api_call(
    method: str,
    path: str,
    params: dict[str, Any] | None = None,
    json_data: dict[str, Any] | None = None,
) -> Any:
    """Make an async HTTP request to the API."""
    client = await get_client()
    headers = _build_headers()

    response = await client.request(method, path, params=params, json=json_data, headers=headers)

    if not response.is_success:
        _raise_error(response)

    if not response.content:
        return {}
    return response.json()

def _build_headers() -> dict[str, str]:
    """Build request headers with auth token."""
    headers: dict[str, str] = {}
    token = os.environ.get(AUTH_ENV_VAR, "")
    if token and ("\r" in token or "\n" in token or "\x00" in token):
        raise RuntimeError(f"{AUTH_ENV_VAR} contains invalid characters")
    if token:
        if AUTH_TYPE == "bearer":
            headers["Authorization"] = f"Bearer {token}"
        elif AUTH_TYPE == "api_key":
            headers["X-API-Key"] = token
    return headers

def _raise_error(response: httpx.Response) -> None:
    """Raise an exception with a friendly error message."""
    messages = {
        401: f"Authentication failed. Set {AUTH_ENV_VAR} environment variable.",
        403: "Permission denied.",
        404: "Resource not found.",
        429: "Rate limited. Try again later.",
    }
    if response.status_code == 422:
        body = response.text[:500]
        raise RuntimeError(f"Validation error: {body}")
    message = messages.get(response.status_code, f"API error {response.status_code}: {response.text[:500]}")
    raise RuntimeError(message)
```

## Security Considerations

### MCP-Specific (from research)

1. **`mask_error_details=True`** — production default, hides stack traces from AI
2. **`ToolError` for user-visible errors** — raw exceptions are masked, only ToolError messages reach the LLM
3. **Never include tokens in tool responses** — they flow into LLM context and can be exfiltrated
4. **Truncate API responses** — cap at 50KB to prevent context window flooding attacks
5. **No `print()` in stdio servers** — corrupts JSON-RPC stream. Use logging to stderr only
6. **Response sanitization** — strip potential prompt injection markers from API response data

### Reused from CLI Generator

7. **Jinja2 SandboxedEnvironment** — prevents template injection
8. **String sanitization** — all graph values escaped before rendering
9. **AST safety walk** — rejects eval/exec/os.system in generated code
10. **`cli_name` validation** — safe Python identifier
11. **`base_url` validation** — no private IPs, HTTPS enforced
12. **Token CRLF prevention** — reject tokens with `\r\n\0`

### Security

- [ ] Generated server uses `ToolError` (not raw exceptions)
- [ ] No `print()` in generated server (stderr/logging only)
- [ ] Token never included in tool return values
- [ ] API responses truncated at 50KB
- [ ] CRLF token validation in generated client
- [ ] All generated code passes AST safety walk

### Non-Functional

- [ ] Generation time < 2 seconds
- [ ] Generated package deps: `fastmcp>=3.0`, `httpx>=0.27` only
- [ ] Adding Streamable HTTP transport later is a config change, not a rewrite

## Dependencies & Risks

| Risk | Mitigation |
|---|---|
| FastMCP API changes in v4+ | Pin `>=3.0,<4.0` in generated pyproject.toml |
| Tool responses too large for LLM context | 50KB truncation limit |
| Prompt injection via API response data | Return JSON strings (structured), strip injection markers |
| stdio transport corrupted by print() | Template never uses print(); logging to stderr only |
| Multiple build types complicate build command | Clean dispatch: type → generator function. Shared context building. |
